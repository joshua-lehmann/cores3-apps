# Fallow audit during workspace migration

The self-hosted Autoflash server embeds the checked-in `tools/autoflash/site/` Vite output. Fallow treats these generated, minified esptool-js chunks as new source after the directory move and reports unused files, circular imports and complexity in them. They are required runtime assets; their module wiring is generated by Vite. The `%BASE_URL%` HTML substitution is also resolved by Vite, not by Fallow.

The move causes Fallow's changed-file attribution to classify the existing Autoflash source as new. Its existing serial-port lifecycle and queue functions retain complexity and duplication findings; they were preserved during the move to avoid changing USB behavior without hardware regression coverage. The release discovery parsing also contains validation branches for untrusted API data. These findings remain visible and should be addressed with dedicated browser and hardware tests rather than suppressed by the migration.
